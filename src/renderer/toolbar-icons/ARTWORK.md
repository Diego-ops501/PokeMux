# Artes da barra superior

Criadas com a ferramenta integrada `image_gen` em 07/10/2026, com fundo transparente. Os arquivos PNG desta pasta são usados por `../toolbar.css`. O ícone do Mercado Global continua sendo o original do jogo em `../market-icon.png`.

Prompt comum (arte nova, uso `stylized-concept`):

> Create a single polished pixel-art game toolbar icon, transparent background. Poke Idle World style: chunky 32-bit RPG inventory sprite, readable at 32px, gold/brass bevels, dark outlines, small jewel-like colorful details, top-left warm highlights. A single centered isolated object fills 80% of square canvas. No lettering, no words, no emoji, no frame, no button plate, no shadows outside object, no extra mini icons.
